What leaves your Mac

Parallex runs on your Mac and keeps your instances, their data and your settings there. This page lists everything it sends anywhere. It's short.

The daily update check

Once a day, and whenever you choose Check for Updates, Parallex asks parallex.mandip.dev whether there's a new version. The request says four things:

X-Parallex-Version: 0.20.0 (this Parallex)
X-Parallex-OS: 26.6 (macOS version)
X-Parallex-Arch: arm64 (Apple silicon or Intel)
X-Parallex-Active: day,week (first check today, this week, this month, or ever)

That's how many Macs use Parallex gets counted, and which versions, without knowing whose they are. There's no identifier: the server can't tell one Mac's checks from another's. It stores a count per day, version, macOS, chip and kind of check, and nothing more. The request also names Parallex and its version in its User-Agent, as apps do.

Like any website, the server sees the address a request comes from while answering it. Parallex doesn't store it and keeps no request logs; for a minute it's used, in memory, to ignore a burst of checks from one place. Cloudflare, which runs the server, handles requests under its own privacy policy.

If the server doesn't answer, Parallex asks GitHub directly instead, and GitHub is told only that a Parallex is checking (it sees the address too, as it does for any download from GitHub). Updates are verified against a signing key built into the app either way, so the server couldn't hand you a bad update even if it wanted to.

You can turn automatic checks off in Settings › About.

The Terminal installer

curl -fsSL https://parallex.mandip.dev/install | sh asks the same server for the latest version and says it's an install, with the macOS version and chip. It's counted the same way.

Things you do yourself

  • Report How It Works opens a GitHub issue with the app's name, its version and how the instance was made filled in. Nothing is sent until you submit it on GitHub, and it never includes instance names or file paths.
  • Website instances talk to the sites you add, like any browser.
  • Getting a site's icon downloads it from that site when you create a website instance.
  • Sponsor and Ko-fi buttons open those pages in your browser.

Nothing else

No analytics inside the app, no crash reporter, no account. The apps you duplicate, your instances' names and anything inside them stay on your Mac. If Parallex ever offers to share more, such as which apps work well as copies, it will be off until you turn it on in Settings, and it will show you exactly what would be sent.

The server's code is public, so you can check all of this.
